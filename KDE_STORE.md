# WhiteSur-dark-herzane

A dark, macOS Big Sur inspired SDDM login theme for KDE Plasma 6.

WhiteSur-dark-herzane brings the clean, elegant look of macOS Big Sur to your
KDE Plasma 6 login screen. It is a standalone SDDM theme split from the
WhiteSur-kde project and updated for Plasma 6 / Qt 6.

## Highlights

- Dark, minimal macOS Big Sur inspired design
- Login screen hides after 5 seconds of inactivity and wakes on mouse or
  keyboard input
- User list or username/password prompt
- Session, keyboard layout, battery and power controls
- Configurable background, logo and accent color
- Turkish and English UI strings
- GPL-3.0 licensed

## Installation

1. Download and extract the archive.
2. Copy the theme folder to `/usr/share/sddm/themes/` (system-wide) or
   `~/.local/share/sddm/themes/` (per-user, if supported).
3. Select **WhiteSur-dark-herzane** in System Settings → Startup and Shutdown →
   Login Screen (SDDM).
