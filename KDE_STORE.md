# WhiteSur-dark-herzane

A dark, macOS Big Sur inspired SDDM login theme for KDE Plasma 6.

Inspired by the WhiteSur-kde project and updated for Plasma 6 / Qt 6, it is an
independent SDDM theme. It also includes an interactive login screen that hides
after 5 seconds of inactivity and wakes on any mouse or keyboard input.

## Installation

1. Download and extract the archive.
2. Copy the theme folder to `/usr/share/sddm/themes/` (system-wide) or
   `~/.local/share/sddm/themes/` (per-user, if supported).
3. Select **WhiteSur-dark-herzane** in System Settings → Startup and Shutdown →
   Login Screen (SDDM).

Alternatively, you can install it quickly from GitHub using the install script:

```bash
git clone https://github.com/herzane52/WhiteSur-dark-herzane.git
cd WhiteSur-dark-herzane
sudo ./install.sh
```
